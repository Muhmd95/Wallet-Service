# Wallet Service Integration Test Documentation

This document describes the `wallet_acid_test.go` integration tests for the Wallet Service. These tests hit the live HTTP endpoint (`http://localhost:8000/v1`) to verify wallet creation and uniqueness constraints.

> **Note:** Direct balance modification endpoints were removed. The wallet balance is now updated asynchronously via the Kafka Connect CDC pipeline consuming from `transactions_db.transactions`.

## Test Scenarios Overview

| Test Name | Concurrency | Purpose |
|-----------|-------------|---------|
| `TestSetup_CreateWallets` | 1 | Creates 5 wallets and verifies each returns 201 with a starting balance of 0. |
| `TestEdgeCase_DuplicateWalletCreation` | 1 | Ensures the unique index on `phone_number` strictly prevents creating two wallets with the same phone number (expects 409 Conflict). |

## How to Run

```bash
go test -v -tags=integration -count=1 ./tests/
```

Requires the Wallet Service to be running on `http://localhost:8000`.
